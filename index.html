Gesture rules

  • Whole header is draggable; taps on its buttons stay taps.
  • Collapsed: up → content height (50% if short, full if long); down → rubber-band.
  • 50%: up → full; down → collapsed. Full: up → rubber-band; down → collapsed (or 50% if the chat fits).
  • Chat scrolls inside the sheet; pulling past the top hands over to the sheet.
  • Snapping: a fast drag (above 800 pt/s) goes to the next state in that direction; a slow release snaps to whichever state is closer.
  • Haptics: a tap is felt when the sheet reaches the next state — mid-drag or as it settles. Android vibrates; iPhone uses the system haptic on iOS 18+.
